# Formato de GLOSSARY.md

`GLOSSARY.md` es el vocabulario oficial de este espacio de trabajo. Todas las
explicaciones, ejercicios y registros de aprendizaje deben usar sus términos.
Construirlo también es parte de aprender: resumir un concepto en una
definición precisa es evidencia de que el usuario lo entiende.

## Estructura

```md
# Glosario de {Tema}

{Una o dos oraciones que describen el tema que cubre este glosario.}

## Términos

**Gancho**:
Los primeros 1 a 3 segundos de un reel, diseñados para que la persona deje de deslizar y se quede.
_Evita_: Intro, arranque

**Retención**:
El porcentaje del reel que la audiencia ve en promedio antes de irse.
_Evita_: Tiempo de visualización, aguante

**Hipertrofia**:
Crecimiento muscular impulsado por la tensión mecánica y el estrés metabólico a lo largo de sesiones de entrenamiento repetidas.
_Evita_: Volumen, ponerse grande
```

## Reglas

- **Agrega un término solo cuando el usuario ya lo entiende.** El glosario es un
  registro de conocimiento comprimido, no un diccionario que el usuario lee para
  aprender. Si el usuario acaba de conocer un concepto, espera a que pueda
  usarlo bien antes de pasarlo aquí.
- **Toma partido.** Cuando haya varias palabras para el mismo concepto, elige
  la mejor y pon las demás como alias que hay que evitar. Así se comprime el
  lenguaje.
- **Definiciones cortas.** Una o dos oraciones. Define qué ES el término, no qué
  hace ni cómo se hace.
- **Usa los términos del glosario dentro de las definiciones.** Una vez que un
  término está en el glosario, prefiérelo en todas partes, incluso dentro de
  otras definiciones. Eso hace que después los términos complejos sean más
  fáciles de entender.
- **Agrupa con subtítulos** cuando aparezcan grupos naturales (por ejemplo,
  `## Edición`, `## Métricas`). Una lista plana está bien cuando los términos
  van juntos.
- **Señala las ambigüedades.** Si un término se usa de forma imprecisa en el
  campo, anota cómo se resuelve aquí: "En este espacio de trabajo, 'vista'
  siempre es una reproducción de 3 segundos o más; las demás se cuentan
  aparte."
- **Corrígelo a medida que la comprensión crece.** Una definición que el
  usuario escribió en la primera semana puede estar mal en la sexta. Actualízala
  ahí mismo; no dejes entradas viejas.
