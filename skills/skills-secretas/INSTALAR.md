# Instala skills-secretas

En Claude Code, pega estos dos comandos:

```
/plugin marketplace add aldushmedia/skills-secretas
/plugin install skills-secretas@skills-secretas
```

Pruébala: escribe «explícame cómo funciona un reel viral, interactivo».

Para las figuras interactivas necesitas Node.js 20 o más reciente.

Si te trabas en algún paso, escríbeme por aquí 👋
